# Dirección de diseño: Nova Import

Sale del mockup que aprobó el cliente. Cambios futuros respetan esto salvo que el cliente pida otra cosa.

- Colores: azul marino #0B1F3A de fondo en encabezado, hero, franja y pie; amarillo #F5C518 como acento; azul #1565D8 en botones sobre blanco.
- Tipografía: Poppins para títulos (logo y títulos de sección en itálica gruesa), Inter para el texto.
- Foco del teclado: amarillo sobre zonas oscuras, azul oscuro #0F4FAE sobre blanco.

## Íconos

Trazo de 2px, puntas redondeadas, 20 a 26px. Es el estilo del mockup aprobado y combina con el peso de Poppins.
Cada ícono nombra el canal o dato que acompaña (WhatsApp, camión de envío, mapa, reloj, mail, Instagram); no se usan como adorno.
Si se suma uno nuevo, tiene que mantener ese mismo trazo y un significado directo.
